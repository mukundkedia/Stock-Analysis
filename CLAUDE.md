# Investment notes

Personal investing notes for an Indian equity portfolio (accounts of Kailash Kumar Kedia and Asha Kedia, broker Ventura Securities).

- `WATCHLIST.md` — every stock we discuss. When a stock is discussed, add it or update its entry (status, positives, risks, re-evaluation checklist, date) and the Action list table.
- `.claude/skills/nbfc-analysis/` — framework for analysing NBFCs/banks. It loads only when a lender is being discussed; don't apply it to other companies.
- `.claude/skills/govt-infra-lenders/` — extra framework and peer list for government infrastructure lenders (REC, PFC, IRFC, IREDA, HUDCO, IFCI). Use with the NBFC guide when one of these is discussed.
- Figures are dated; refresh prices and results before acting. This is research, not financial advice.
